Unit 1

OOP Basics & JVM Architecture

Java compiles source code into Bytecode executed by the Java Virtual Machine (JVM). Core pillars: Encapsulation, Inheritance, Polymorphism, and Abstraction.

Unit 2

Constructors, static & final

Constructors initialize objects using new. static members are shared across the class, and final defines constants.

class Student {
  String name;
  Student(String name) { this.name = name; }
}
Unit 3

Inheritance & Polymorphism

Use extends for IS-A inheritance and @Override for runtime method overriding.

class Dog extends Animal {
  @Override void sound() { System.out.println("Bark"); }
}
